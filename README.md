# StyleBox — Telegram Mini App
## Описание проекта
StyleBox — это Telegram Mini App для персонализированного подбора и продажи модной одежды. Приложение работает прямо внутри мессенджера Telegram, не требуя установки дополнительного ПО.
## Стек технологий
- HTML5, CSS3, JavaScript (ES6+)
- Telegram WebApp SDK
- Git, GitHub
- Git LFS (для тяжелых файлов)
## Модульная архитектура (MVP)
Для работы минимального функционала (MVP) выделены два независимых модуля:
### Модуль 1 — Модуль каталога (Catalog Module)
**Назначение:** отображение списка товаров, фильтрация по категориям, показ карточки товара.
**Функции:** `renderMainPage()`, `filterByCategory()`, `showProductModal(product_id)`.
**Данные:** массив `products[]` с объектами товаров.
### Модуль 2 — Модуль корзины (Cart Module)
**Назначение:** добавление, удаление и изменение количества товаров, подсчёт итоговой суммы.
**Функции:** `addToCart(product_id)`, `removeFromCart(product_id)`, `renderCart()`.
**Данные:** объект `state.cart` с товарами и их количеством.
## Схема взаимодействия модулей

┌─────────────────────┐ product_id ┌─────────────────────┐
│ │ ─────────────────────────► │ │
│ Модуль каталога │ │ Модуль корзины │
│ (Catalog Module) │ ◄───────────────────────── │ (Cart Module) │
│ │ cart_count │ │
└─────────────────────┘ └─────────────────────┘

**Описание потока данных:**
1. Пользователь нажимает кнопку «В корзину» на карточке товара.
2. Модуль каталога передаёт `product_id` в Модуль корзины.
3. Модуль корзины добавляет товар в `state.cart` и возвращает `cart_count`.
4. Модуль каталога обновляет интерфейс (счётчик корзины, статус кнопки).
